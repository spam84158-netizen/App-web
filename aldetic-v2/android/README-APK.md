# APK Aldetic (squelette WebView)
- Ouvrir le dossier `android/` dans Android Studio. Ajouter build.gradle, settings.gradle et la dépendance appcompat.
- Remplacer `ADRESSE_OFFICIELLE_DU_SITE` dans MainActivity.kt.
- Logo : l'icône officielle reste à créer et valider (cahier 1.5). Aucune icône n'est incluse.
- Compiler : Build > Build APK (debug), puis Build > Generate Signed Bundle/APK (release). La clé de signature ne doit jamais être dans le dépôt.
- Ce squelette n'a pas été compilé ni testé dans cet environnement.
