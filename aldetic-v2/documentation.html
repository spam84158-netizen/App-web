Premiers pas

Créez un compte, puis un projet depuis votre tableau de bord. Votre projet reçoit un dépôt sur MY GIT.

MY GIT depuis Termux

Extrayez votre archive sur le téléphone, puis envoyez les fichiers vers votre dépôt. Remplacez l'adresse par celle affichée sur la page de votre dépôt.

pkg install git unzip
cd ~/storage/downloads
unzip MONPROJET.zip -d MONPROJET
cd MONPROJET
git init
git add .
git commit -m "Initial project upload"
git branch -M main
git remote add origin ADRESSE_AFFICHEE_SUR_LE_SITE
git push -u origin main

Ne mettez jamais de mot de passe ou de jeton dans une commande. Git vous demandera de vous authentifier.

Importer un ZIP

MY CLOUD accepte les archives ZIP dans la limite de votre quota. Les archives sont vérifiées avant extraction, et rien ne s'exécute automatiquement.

Sécurité et secrets

Gardez les clés et mots de passe hors des dépôts. Utilisez des variables d'environnement. Si un secret est exposé, révoquez-le immédiatement.
